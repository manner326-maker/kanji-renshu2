# かんじれんしゅう2（Web版・手書き自動採点つき）

かんじれんしゅう（v0.2.1）に、①④の手書き自動採点と、おうちの人による答案のふりかえり・訂正を加えた版です。v1 とは保存場所が別なので、同じサイトに並べて置いても問題集や記録は混ざりません。

## 置き方（GitHub Pages）

1. GitHub で新しいリポジトリ `kanji-renshu2` を Public で作る。
2. 「uploading an existing file」から、このフォルダの中身をアップロードする。**recognizer フォルダはフォルダごと**ドラッグする（中の4ファイルが `recognizer/` の下に入っていればOK）。
3. Settings → Pages で Branch を `main` / `/ (root)` にして Save。
4. `https://ユーザー名.github.io/kanji-renshu2/` を iPad の Safari で開き、「ホーム画面に追加」。

初回だけ手書き認識データ（約6.7MB）を読み込みます。一度開けば、以後は通信なしでも自動採点できます。

## 追加した機能

- **1マス1文字の書き取り欄**：4×3のマスに1字ずつ書く。各線は、その線の中心があるマスの字として扱う。左上から右へ、次の行へと読む。
- **①④の自動採点**：「こたえ」を押した時点の筆跡を端末内で読み取り、問題集の漢字（A列）と完全一致なら○、ちがえば△。判定はそのまま得点と復習に使う。子どもは答え画面で判定を変えられない。
- **自己採点になる場合**：読み取れなかったとき、対応外の字（小さい「ゃ・っ」、カタカナ、一部の漢字）を含むとき、紙で答えたとき、何も書かなかったとき、②③。
- **答案のふりかえり（おうちの人へ）**：各回の答案（筆跡・読み取った字・判定方法）を一覧で見て、○／△ を直せる。直すとその回の得点と、その問題の復習状態がすぐ更新される（その後にもっと新しい回答がある場合は、新しい方の状態を優先）。
- **CSV取込時の警告**：自動採点できない字を含む行を表示。
- 設定で自動採点をオフにすると、v1 と同じ自己採点に戻る。

## 保存

判定は直近50回分、筆跡は直近10回分。容量が足りなくなったら古い回の筆跡から消す（判定と得点は残る）。

## 手書き認識の精度（事前確認）

元データを崩した字での試験結果。実際の子どもの字では変わるので、ふりかえり画面で確認してください。

| 対象 | 崩し 弱 | 崩し 中 | 崩し 強 |
|---|---|---|---|
| 漢字（300字） | — | 約85％ | 約71％ |
| ひらがな（71字） | 約85％ | 約62％ | — |

ひらがなは画数が少なく形が似ているものが多いため、同じ崩し方でも漢字より読み違えが増えます（例：る→く、れ→わ）。
